# Origins and scope

The verification approach was inspired by Lauren Tan (poteto)'s talk and
[pstack](https://github.com/cursor/plugins/tree/main/pstack), including repeatable
app control, feature maps, reproducing failures, and evaluating agent behavior.
This project is an independently maintained, portable implementation of those
ideas. It is not a pstack installation or an official Cursor, Claude, Codex, or
Grok Bot product.

An earlier local setup used the optional recorder and source guide from
[michaelshimeles/skills](https://github.com/michaelshimeles/skills/tree/main/evidence-driven-testing).
That repository had no declared license when checked on 2026-10-11. Those files
are not redistributed here or covered by this project's MIT license. The public
evidence skill instead uses a recorder already supported and authorized by the
host, or screenshots and direct behavior checks when sufficient.

The source video's transcript, screenshots, downloaded media, private agent
instructions, account information, and local session logs are not included.
